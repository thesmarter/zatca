# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| ^1.0    | :white_check_mark: |
| < 1.0   | :x:                |

Only the latest `^1.0` release line receives security fixes. If you are on
an older version, please upgrade before reporting.

## Reporting a vulnerability

Email **[security@smart.sd](mailto:security@smart.sd)** with:

- a description of the vulnerability,
- steps to reproduce or a proof of concept,
- the package version and PHP version affected,
- any suggested mitigation, if known.

Please do **not** open a public issue for security reports.

## Disclosure

We aim to acknowledge reports within 5 business days and to ship a fix as
quickly as possible depending on severity. We follow a **90-day disclosure
window**: after a fix is released (or 90 days from the report, whichever
comes first), the vulnerability may be publicly disclosed with credit to
the reporter unless otherwise agreed.
